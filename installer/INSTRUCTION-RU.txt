Farm Edge — краткая инструкция
================================

1) На сайте https://farm.5dsap.ru войдите как владелец.
   В верхней карточке Farm Edge на вкладке «Принтеры»:
   «Скачать для Windows» → «Получить код привязки». Скопируйте код.

2) На Farm PC с Farm BFF (в сети с принтерами):
   - скачайте и запустите FarmEdge-Setup.exe
   - Next → Установить (как обычная программа Windows)
   - после установки откроется окно: вставьте код → «Подключить»

3) Снова откройте верхнюю карточку Farm Edge на сайте —
   статус должен стать «Агент онлайн».

Проброс портов роутера НЕ нужен.
Удаление: Параметры Windows → Приложения → Farm Edge → Удалить
  (+ в облаке «Отозвать»).

Windows / браузер предупреждает «неопознанное приложение», «файл может
быть опасен» — это SmartScreen для программ без подписи издателя.
Скачивайте только с farm.5dsap.ru, сверьте SHA-256 с FarmEdge-SHA256.txt
(PowerShell: Get-FileHash .\FarmEdge-Setup.exe -Algorithm SHA256),
затем «Подробнее» → «Выполнить в любом случае».

Статус «привязан · офлайн» при включённом ПК — агент отозван в облаке.
Получите новый код и запустите Пуск → Farm Edge → «Подключить Farm Edge»:
с новым кодом агент перепривязывается заново.

Запасной вариант без .exe: архив FarmEdge-Setup-win.zip → Install-FarmEdge.bat
